# Аудит и рефакторинг, 6 ноября 2026

База аудита — `eb030df` (main после PR #42). Работа ведётся в отдельной
ветке `codex/audit-refactor`. На этапе аудита production, пользовательские данные,
env и VPS не менялись. Выпуск разрешён пользователем отдельным запросом после
завершения аудита; его состояние ниже. Локальные документы другого чата не переносятся
поверх актуальных файлов main.

## Источники и границы

Изучены доступная переписка, исходники, миграции, сборщик, тесты и профильные
документы. Полного журнала прежних ответов и проверок в этом контексте нет.
Описание текущего поведения опирается на код и воспроизводимые проверки.
Частные архивы и стартовые десять мест не считаются production-данными.

## План по приоритету

1. Проверить и исправить атомарность пакетного импорта календаря, обработку
   запоздалых ответов авторизации, валидацию некорректных запросов и защиту
   исходников при очистке каталога сборки. До исправлений — регрессионные тесты.
2. Разделить маршрутизатор API и операции каталога, статусов, состояния места.
   Свести повторяющуюся настройку браузерного клиента к одному модулю.
   Сохранить URL, ответы, роли, версии данных и транзакционные гарантии.
3. Привести документацию к фактической архитектуре Node/SQLite, общему плану
   поясов и личным пушам. Отделить исторические Cloudflare/Drizzle-заготовки
   от действующей схемы SQL. Новые продуктовые функции не добавлять.
4. Повторить автоматические проверки, сборку Pages и визуальные сценарии
   карты/календаря на мобильной и десктопной ширине, в обеих темах.

## Исходная проверка

156 тестов проходят до изменений, включая локальный HTTP adapter, авторизацию,
права, миграции, версии, планировщик, отправку пушей через тестовый транспорт,
таймзоны и Pages. Запуск выполнен Node 24 напрямую, поскольку npm отсутствует
в доступном runtime. Использованы уже установленные зависимости с идентичным
`package-lock.json`, без изменения lockfile. Физический iPhone, реальная
доставка пушей и конфигурация рабочего VPS этим не проверяются.

## Обнаруженное вне продуктового рефакторинга

- Справка обещает удаление статусов, но UI и API поддерживают только создание
  и редактирование. В этой задаче исправляется описание, новая операция не вводится.
- Исторический CSV-импорт использует исходные маршрутные тексты для summary/tip
  и создаёт непроверенные часы. Его нельзя запускать как редактор актуальных
  карточек без подготовки полей по нынешним правилам и проверки пакета.
- JSON-экспорт — переносимая выборка данных, а не полная резервная копия.
  Учётные данные, устройства и личные напоминания требуют SQLite backup.
- Проверка настоящих пушей на iPhone и внешнего хранения резервных копий
  остаётся эксплуатационной задачей и не требует переписывания приложения.

## Что оставлено и почему

1. **Эксплуатационная проверка:** физический iPhone/PWA, Face ID, реальная
   доставка push при закрытом приложении, Docker build, внешнее хранение backup
   и восстановление рабочего VPS не проверялись. Production обновлён после
   отдельного разрешения; проверки выпуска описаны ниже. Мок транспорта
   и браузерная эмуляция не заменяют устройство.
2. **Оставшийся технический долг:** orchestration карты/календаря и часть HTML
   templates по-прежнему крупные и компактно записанные. Они работают и имеют
   отдельные модули модели/жестов/полей. Переписывать все формы или вводить
   frontend-фреймворк ради этого аудита нецелесообразно. Следующий выделяемый
   блок — форма записи календаря, когда появится связанная продуктовая задача.
3. **Исторические инструменты:** CSV importer не должен повторно заполнять
   вычитанные карточки исходными маршрутными текстами. Его применение требует
   подготовленного пакета. Полный JSON restore не добавлялся: восстановление
   аккаунтов и личных данных выполняется из SQLite backup.
4. **Принятые границы:** bearer token остаётся доступен доверенному JavaScript
   общего origin github.io; длительность сессии и пароль от шести символов
   сохраняют согласованное поведение. Новая политика безопасности в рефакторинг
   не включалась. Публичный DNS API и внешние подложки остаются зависимостями.
