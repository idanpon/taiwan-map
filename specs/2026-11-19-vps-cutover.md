# Перенос Taiwan Map на постоянный домен API

Статус: сайт опубликован, личная авторизация ChatGPT ожидает владельца. 19 ноября 2026. Основание — перенос проекта на заменяющий VPS до отключения прежнего. [Размещение](../docs/DEPLOYMENT.md), [личный коннектор](../docs/CHATGPT_PLUGIN.md).

Интерфейс остаётся на GitHub Pages. Действующий HTTPS нового сервера обслуживает `taiwan.svobodadlaseti.beer`. Карту, планировщик, PWA и пакет MCP нужно перевести на него. Сохраняются данные поездки, документы, личные настройки, ключи Web Push, RP ID для passkeys и границы OAuth resource. Сессии браузера привязаны к конкретному API. Для нового адреса доступен штатный вход.

1. Сверить фактические службы, оба хранилища, DNS, TLS и настройки идентификации. Сохранить полные комплекты обеих сторон перед переключением.
2. Передать запись одной службе. Сверить все таблицы и файлы, включая данные вне публичного экспорта. Сохранить расхождения до любого выбора исходной копии.
3. Выпустить адрес API и метаданные MCP из main. Проверить опубликованные страницы, CORS, приватные границы, доступные способы входа, OAuth discovery и подключение.
4. Подтвердить работу после изоляции прежней службы. Задокументировать отсечку записи, доставку и необходимые действия в клиентских приложениях.

## Результат

19 ноября 2026 года в 08:14 МСК прежняя служба Taiwan Map остановлена, её автозапуск отключён. Старый HTTPS-маршрут временно пересылает запросы на постоянный домен. На новом VPS служба включена в автозапуск. Файлы остальных приложений при переключении маршрута не менялись.

До переключения и после остановки прежней службы сохранены комплекты базы и документов обеих сторон. Четыре архива сверены по SHA-256 с VPS и восстановлены в зашифрованном образе на Mac. Финальные восстановленные базы совпали по схеме и содержимому всех 68 таблиц. Готовых файлов и незавершённых загрузок на отсечке было ноль. Сравнение настроек подтвердило сохранность ключей Push и параметров входа.

[PR #92](https://github.com/idanpon/taiwan-map/pull/92) и [производственный выпуск](https://github.com/idanpon/taiwan-map/actions/runs/44463871877) завершены. Прошли 357 локальных тестов, сборка и штатная проверка 88 опубликованных файлов. Проверены DNS, TLS, публичный каталог, CORS, отказы в приватном API без сессии, конфигурация входа и OAuth discovery. На финальной восстановленной базе отдельная тестовая учётная запись прошла вход, чтение закрытой карты и плана model3, продление сессии и выход. Биометрия, подтверждение Telegram и доставка Push на реальное устройство требуют участия владельца.

В репозитории обновлены адрес и OAuth resource пакета. Для личного подключения ChatGPT создан новый сценарий привязки к постоянному домену с прежним публичным client ID, PKCE и областями поездки. Старое установленное приложение продолжает указывать на адрес с прежним IP. Для завершения нового подключения владелец входит в карту, возвращается на страницу согласия, нажимает «Повторить» и «Разрешить подключение». Следующая проверка после согласия — чтение поездки через новое подключение.
